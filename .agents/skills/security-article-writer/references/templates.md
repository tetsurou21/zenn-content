# 記事テンプレート集

記事の目的（パターンA：脆弱性技術解説 / パターンB：インシデント分析 / パターンC：複合型）に応じて、以下の構成をベースに執筆してください。見出しは対象トピックに合わせて柔軟に調整して構いません。

## 概要

- **何が起きたか**: <対象ソフトウェア>に<脆弱性の種類（例：リモートコード実行、認証バイパスなど）>の脆弱性（**CVE-XXXX-YYYY**）が発見・公開された。

## パターンC：複合型（脆弱性＋悪用インシデント）の構成案

特定の脆弱性が実際に悪用されてインシデントに発展した場合（ゼロデイ攻撃事案など）は、パターンAとパターンBを組み合わせて以下の順序で構成します。

1. **はじめに（要約・緊急度・今すぐやるべき対策）**
2. **脆弱性の基本情報（CVE・対象バージョン・CVSS）**
3. **インシデントの発生経緯とタイムライン（どのように悪用が確認されたか）**
4. **脆弱性の技術的な仕組みと攻撃フロー（Mermaid図解＋コード/仕様解説）**
5. **侵害指標（IoC：攻撃を受けた痕跡の確認方法）と対策（アップデート・緩和策）**
6. **まとめ・参考資料（一次情報リンク）**
